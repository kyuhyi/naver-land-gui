# 네이버 부동산 매물 조회기

동 이름 하나로 그 동네 아파트 단지와 매물을 통째로 훑어 표로 뽑는 데스크톱 앱입니다.
호가 변동, 관리비, 확인일, 중개사까지 한 화면에 놓고 정렬·필터하고 CSV 로 저장합니다.

윈도우 · 맥 둘 다 돕니다.

---

## 1. 설치

### 받기

**[최신 실행파일 받기 →](../../releases/tag/build-latest)**

| 파일 | 어디에 |
|------|--------|
| `BSD-NaverLand.exe` | 윈도우 64비트 |
| `BSD-NaverLand-macos-arm64.zip` | 맥 · M1 이후 (Apple Silicon) |
| `BSD-NaverLand-macos-x86_64.zip` | 맥 · 인텔 |

맥이 어느 쪽인지 모르겠으면 터미널에서 `uname -m` — `arm64` 면 위, `x86_64` 면 아래.

### 준비물 두 가지

1. **구글 크롬** — 앱에 크롬은 들어 있지 않습니다. 설치돼 있어야 합니다.
2. **국내 IP** — 해외·VPN·클라우드 서버에서는 네이버가 응답 자체를 주지 않습니다.
   연결은 되는데 그대로 타임아웃됩니다.

파이썬은 필요 없습니다.

### 윈도우

받은 `BSD-NaverLand.exe` 를 더블클릭하면 끝입니다.
SmartScreen 이 막으면 **추가 정보 → 실행**.

한 파일로 압축돼 있어 첫 실행은 10초쯤 걸립니다.

### 맥

압축을 풀고 `BSD-NaverLand.app` 을 `응용 프로그램` 으로 옮긴 뒤,
Finder 에서 앱을 **우클릭 → 열기 → 다시 열기**.

> 그냥 더블클릭하면 열리지 않습니다. 개발자 인증서로 서명한 앱이 아니라서
> Gatekeeper 가 한 번 막습니다. 첫 실행만 우클릭으로 열면 그 뒤로는 더블클릭으로 됩니다.

**「손상되었기 때문에 열 수 없습니다. 휴지통으로 이동」이 뜨면** 터미널에서:

```bash
xattr -cr BSD-NaverLand.app && codesign --force --deep --sign - BSD-NaverLand.app
```

격리 속성을 지우고 ad-hoc 서명을 다시 채웁니다. `xattr` 만으로는 안 풀립니다.

### 잘 깔렸는지 확인

창을 띄우지 않고 크롬 연결 → 단지 조회 → 매물 조회까지 실제로 해 봅니다.

```bash
# 맥
BSD-NaverLand.app/Contents/MacOS/BSD-NaverLand --selftest
cat ~/Library/Logs/BSD-NaverLand/selftest.log

# 윈도우
BSD-NaverLand.exe --selftest
type selftest.log
```

끝줄이 `SELFTEST PASS` 면 정상입니다.

## 2. 쓰는 법

처음 실행하면 **크롬 창이 하나 새로 뜹니다.** 평소 쓰는 크롬과 분리된
프로필(`~/.naver_land_profile`)이라 로그인 정보나 방문기록이 섞이지 않습니다.
**닫지 말고 두면 다음 검색이 빨라집니다.**

### 크롬 창에서 진행 상황 보기

그 크롬 창 오른쪽에 실시간 패널이 뜹니다. 지금 어느 단지를 조회 중인지,
어떤 API 를 때리고 있는지, 방금 찾은 매물이 무엇인지 그대로 보입니다.

```
BSD 매물 조회기  LIVE
매물 수집 중… 12/37  목동현대하이페리온
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
단지 12   매물 418   경과 2:41
지금 요청  /front-api/v1/complex/article/list
방금 찾은 매물
  목동우성2차     13억 3,000   84.96 · 11/15
  목동우성2차     15억         113.91 · 중/15
기록
  14:58:44 [12/37] 목동현대하이페리온 — 31건 (누적 418건)
```

패널 오른쪽 위 **—** 를 누르면 접힙니다. 사이드바의 **「크롬 창에 진행 표시」**
로 끌 수 있습니다.

> 이 패널은 이미 열려 있는 페이지에 그림만 얹는 것이라 **요청이 늘지 않습니다.**
> 수집 속도와 차단 위험에 영향이 없습니다. 「크롬 창 숨김」을 켜면 자동으로 꺼집니다.

### 검색 방식 네 가지

왼쪽에서 고릅니다.

| 방식 | 하는 일 | 걸리는 시간 |
|------|---------|------------|
| **지역 검색** | 동 이름 → 그 반경 안의 단지 전부 → 매물 전량 | 동 하나에 5~10분 |
| **단지 매물** | 단지번호 하나의 매물을 페이지 넘김까지 전량 | 10초 안팎 |
| **단지 정보** | 이름·주소·세대수·준공연도·매물 건수만 | 5초 |
| **지도 영역** | 경위도 사각형을 직접 지정 | 범위에 따라 |

가장 많이 쓰는 건 **지역 검색**입니다. 지역 칸에 `서울시 양천구 신정동` 처럼 적고
거래유형(매매/전세/월세)을 고른 뒤 **검색 시작**을 누르면 됩니다.

**단지번호**는 네이버 부동산에서 단지를 열었을 때 주소 끝에 붙는 숫자입니다.
`…/complexes/8742?tab=article` → `8742`

### 오래 걸리는 게 정상입니다

조회 한 건마다 **0.8초를 쉽니다.** 동 하나를 통째로 훑으면 단지 100개가 넘고
그만큼 요청이 나가서 몇 분 걸립니다. 진행 상황은 아래 기록창과 상태줄에 나옵니다.

간격을 줄이면 429(요청 과다)로 한동안 막힙니다. 왼쪽 아래 `요청 간격` 을
줄이지 마세요. 오히려 자주 막히면 1.2초 이상으로 올리는 게 낫습니다.

### 결과 다루기

- **머리글 클릭 정렬** — 가격·월세·관리비는 `13억 7,000` 이라는 글자가 아니라
  **금액 기준**으로 정렬됩니다
- **표에서 찾기** (`Ctrl/⌘+F`) — 단지명·층·향·중개사·특징까지 모든 칸을 훑습니다
- **CSV 저장** (`Ctrl/⌘+S`) — 지금 화면에 **보이는 행**을 저장합니다. 필터·정렬이 반영됩니다
- **우클릭** — 네이버에서 열기 / 이 단지 매물만 다시 조회 / 행·번호 복사
- **단지 탭에서 행 더블클릭** — 그 단지의 매물 조회로 넘어갑니다

위쪽 요약칸에 건수 · 최저 · 중위 · 최고가와 **호가 변동**(▼내림 ▲올림)이 나옵니다.
호가를 내린 매물만 보려면 찾기 칸에 `▼` 를 넣으면 됩니다.

### 단축키

| 키 | 동작 |
|----|------|
| `Ctrl/⌘ + Enter` | 검색 시작 |
| `Esc` | 중지 |
| `Ctrl/⌘ + F` | 표에서 찾기 |
| `Ctrl/⌘ + C` | 선택 행 복사 |
| `Ctrl/⌘ + S` | CSV 저장 |

## 3. 안 될 때

| 증상 | 원인과 해결 |
|------|------------|
| 429 가 뜬다 | 요청이 잦습니다. 몇 분 뒤 재시도하거나 `요청 간격` 을 1.2초 이상으로 |
| 인증 거부 (401/403) | 떠 있는 크롬 창에서 네이버 부동산을 직접 한 번 열어 본 뒤 재시도 |
| 응답이 없다 / 타임아웃 | 해외 IP 입니다. VPN 을 끄고 국내에서 실행하세요 |
| 크롬을 찾지 못한다 | 환경변수 `CHROME_PATH` 에 크롬 실행파일 경로를 지정 |
| (맥) 손상됐다며 안 열린다 | 위 **설치 → 맥** 참고. `xattr -cr` + `codesign` |
| (윈도우) 창이 안 뜬다 | 실행파일 이름에 한글이 있으면 조용히 죽습니다. ASCII 이름으로 바꾸세요 |
| 결과가 0건이다 | 검색 반경을 넓히거나 거래유형·매물종류를 바꿔 보세요 |

오류가 나면 로그가 남습니다 — 맥은 `~/Library/Logs/BSD-NaverLand/error.log`,
윈도우는 실행파일 옆 `error.log`.

## 4. 소스에서 실행

```bash
pip install -r requirements.txt
python app.py
```

더블클릭으로 열려면 — 윈도우는 `run.bat`, 맥·리눅스는 `run.command`.

`playwright install` 은 필요 없습니다. 이미 깔려 있는 구글 크롬을 그대로 씁니다.
Python 3.9 이상.

터미널만 쓰고 싶다면 조회 엔진을 직접 부를 수 있습니다.

```bash
python naver_land.py region "서울시 양천구 신정동" --articles --csv 신정동.csv
python naver_land.py complex 8742 --trade A1 --csv 목동우성2차.csv
python naver_land.py info 8742
python naver_land.py info 8742 --no-hud     # 크롬 패널 없이
```

## 5. 직접 빌드

```bash
pip install pyinstaller pillow
python build_app.py
```

돌린 OS 에 맞는 것이 나옵니다.

| OS | 결과물 |
|----|--------|
| Windows | `dist/BSD-NaverLand.exe` (81MB, 한 파일) |
| macOS | `dist/BSD-NaverLand.app` + 배포용 `BSD-NaverLand-macos-<arch>.zip` |
| Linux | `dist/BSD-NaverLand/BSD-NaverLand` |

원인을 바로 보고 싶으면 콘솔이 뜨는 폴더 형태로:

```bash
python build_app.py --debug
```

### GitHub 에서 굽기

**PyInstaller 는 크로스 컴파일이 안 됩니다.** 맥용은 맥에서, 윈도우용은
윈도우에서 빌드해야 합니다. 둘 다 없으면 GitHub 러너가 대신 굽습니다.

```bash
gh workflow run build.yml                     # 전부
gh workflow run build.yml -f platform=맥만
gh workflow run build.yml -f platform=윈도우만
```

끝나면 `build-latest` 릴리스에 덮어써집니다.
macOS 러너는 분당 사용량이 **10배**, Windows 는 **2배**로 계산되니 필요할 때만 돌리세요.

### 빌드하다 밟은 지뢰 두 개

만들면서 실제로 걸렸던 것들입니다. 고쳐 뒀지만 손댈 때 알고 있어야 합니다.

**1. 실행파일 이름은 반드시 ASCII.**
onefile 부트로더는 파일명에 한글이 들어가면 임시폴더 압축 해제에 실패하고
**창도 오류도 없이 종료코드 0 으로** 끝납니다. 창 제목과 Dock 이름에는
한글이 그대로 나오니 보이는 데는 지장 없습니다.

**2. 맥 번들의 `Info.plist` 를 고치면 서명이 깨진다.**
PyInstaller 는 `.app` 을 ad-hoc 서명해 두는데, 그 뒤에 plist 를 건드리면
코드 디렉터리 해시가 어긋납니다. Apple Silicon 은 서명이 깨진 앱의 실행을
거부하고 「손상되었기 때문에 열 수 없습니다」를 띄웁니다.
**격리 속성 문제가 아니라서 `xattr` 로는 안 풀립니다.**
`build_app.py` 가 plist 를 고친 뒤 재서명하고 검증합니다. 검증에 실패하면
zip 을 만들지 않고 빌드를 세웁니다.

## 6. 어떻게 도는가

네이버 부동산의 매물 목록은 화면 주소로 오지 않습니다. 페이지가 열린 뒤
자바스크립트가 별도 API 를 POST 로 호출해 받아옵니다.

그 API 는 토큰을 쓰지 않는 대신 세 가지를 봅니다 — **국내 IP 인가**, **쿠키가
있는가**, **진짜 브라우저인가**. 세 번째가 핵심입니다. 헤더는 흉내낼 수 있지만
파이썬·curl 의 TLS 접속 지문은 크롬이 아니라서, 브라우저에서 쿠키를 그대로
복사해 `requests` 로 보내도 첫 요청부터 429 로 거절당합니다.

그래서 흉내내기를 포기합니다. **진짜 크롬을 띄우고 그 페이지 안에서 `fetch()` 를
실행시킵니다.** 쿠키·헤더·TLS 지문이 전부 진짜 크롬 것이라 우회할 것이 남지 않습니다.

```
파이썬 ──(CDP)──▶ 진짜 크롬 ──(fetch)──▶ 네이버 API
```

차단을 뚫은 것이 아니라, 차단이 없는 자리에서 실행하는 것입니다.

### 파일

| 파일 | 역할 |
|------|------|
| `app.py` | 창·화면·흐름 |
| `worker.py` | 백그라운드 스레드 — 조회·취소·진행률 |
| `models.py` | 표 모델 — 금액 기준 정렬, 전열 필터 |
| `theme.py` | 다크 팔레트와 스타일시트 |
| `naver_land.py` | 조회 엔진 (터미널 단독 실행도 가능) |
| `hud.py` | 크롬 창 안의 실시간 진행 패널 |
| `selftest.py` | `--selftest` 자가진단 |
| `build_app.py` | 실행파일 빌드 — Windows·macOS·Linux |
| `.github/workflows/build.yml` | 러너에서 굽고 릴리스에 올리기 |
