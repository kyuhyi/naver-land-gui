# BSD · 네이버 부동산 매물 조회기 (PySide6 다크 GUI)

`naver_land.py` 의 조회 로직을 그대로 쓰는 데스크톱 앱입니다.
실제 크롬을 CDP 로 붙잡고 그 페이지 안에서 `fetch()` 를 실행해 네이버 부동산
내부 API 를 호출합니다. (원리는 `naver_land.py` 맨 위 주석 참고)

## 실행

```bash
pip install -r requirements.txt
python app.py
```

더블클릭으로 열려면 — 윈도우는 `run.bat`, 맥·리눅스는 `run.command`.
`playwright install` 은 필요 없습니다 — 이미 깔려 있는 구글 크롬을 그대로 씁니다.

준비물: 구글 크롬 설치 · **국내 IP** · Python 3.9 이상
(해외·데이터센터 IP 에서는 네이버가 응답 자체를 주지 않습니다.)

### 단독 실행파일로 만들기

```bash
pip install pyinstaller
python build_app.py
```

돌린 OS 에 맞는 것이 나옵니다.

| OS | 결과물 |
|----|--------|
| Windows | `dist/BSD-NaverLand.exe` (81MB, 한 파일) |
| macOS | `dist/BSD-NaverLand.app` + 배포용 `BSD-NaverLand-macos-<arch>.zip` |
| Linux | `dist/BSD-NaverLand/BSD-NaverLand` |

파이썬이 없는 PC 에서도 더블클릭으로 실행되지만,
**구글 크롬은 그 PC 에 설치돼 있어야 합니다** (크롬은 포함되지 않습니다).

> **실행파일 이름은 반드시 ASCII 로 두세요.** PyInstaller 의 onefile 부트로더는
> 파일명에 한글이 들어가면 압축을 풀지 못하고 **창도 오류도 없이 종료코드 0 으로
> 조용히 끝납니다.** 창 제목과 작업표시줄에는 한글 이름이 그대로 나오니
> 보이는 데는 지장이 없습니다.

빌드가 제대로 됐는지 확인하려면:

```bash
dist\BSD-NaverLand.exe --selftest
```

창을 띄우지 않고 크롬 연결 → 단지 조회 → 매물 조회까지 실제로 해 본 뒤
exe 옆에 `selftest.log` 를 남깁니다. 마지막 줄이 `SELFTEST PASS` 면 정상입니다.
실행 중 오류가 나면 오류 창이 뜨고 `error.log` 가 exe 옆에 쌓입니다.

문제 원인을 바로 보고 싶으면 콘솔이 뜨는 폴더 형태로 빌드하세요.

```bash
python build_app.py --debug
```

```
┌──────────┬──────────────────────────────────────────────┐
│ BSD 로고  │  지역 검색                    [중지] [검색 시작] │
│          ├──────────────────────────────────────────────┤
│ 지역 검색 │  검색 조건 — 지역 / 반경 / 상한 / 거래유형 / 종류 │
│ 단지 매물 ├──────────────────────────────────────────────┤
│ 단지 정보 │  건수 · 최저가 · 중위가 · 최고가 · 호가변동       │
│ 지도 영역 ├──────────────────────────────────────────────┤
│          │  [매물] [단지]  표 — 정렬 · 필터 · CSV          │
│ 설정      ├──────────────────────────────────────────────┤
│ 브라우저  │  진행 기록                                     │

```

### 검색 방식 네 가지

| 방식 | 하는 일 |
|------|---------|
| **지역 검색** | 동 이름 → 좌표 → 그 반경 안의 단지 전부 → (선택) 매물 전량 |
| **단지 매물** | 단지번호 하나의 매물을 페이지 넘김까지 전량 |
| **단지 정보** | 이름·주소·세대수·준공연도·매물 건수만 빠르게 |
| **지도 영역** | 경위도 사각형을 직접 지정 |

단지번호는 네이버 부동산에서 단지를 열었을 때 주소 끝에 붙는 숫자입니다.
`…/complexes/8742?tab=article` → `8742`

### 표에서 할 수 있는 것

- 머리글 클릭 정렬 — 가격·월세·관리비는 글자가 아니라 **금액 기준**으로 정렬됩니다
- 위쪽 검색칸으로 모든 칸을 훑는 즉시 필터
- 우클릭 → 네이버에서 열기 / 이 단지 매물만 다시 조회 / 행·번호 복사
- 단지 탭에서 행을 더블클릭하면 그 단지의 매물 조회로 넘어갑니다
- **CSV 저장** 은 "지금 화면에 보이는 행"(필터·정렬 반영)을 저장합니다

## 알아 둘 것

- **첫 실행 때 크롬 창이 하나 새로 뜹니다.** 평소 쓰는 크롬과 분리된
  프로필(`~/.naver_land_profile`)이라 로그인 정보가 섞이지 않습니다.
  닫지 말고 두면 다음 검색이 빨라집니다. (사이드바 「크롬 미리 띄우기」)
- **조회 한 건마다 0.8초를 쉽니다.** 동 하나를 통째로 훑으면 몇 분 걸립니다.
  정상입니다. 간격을 줄이면 429(요청 과다)로 한동안 막힙니다.
- 「크롬 창 숨김」은 차단될 수 있어 권장하지 않습니다.
- 개인적인 열람 목적으로만 쓰세요. 수집한 자료를 그대로 재배포하지 마세요.

### 자주 나오는 오류

| 메시지 | 원인과 해결 |
|--------|------------|
| 429 | 요청이 잦음. 몇 분 뒤 재시도하거나 요청 간격을 1.2초 이상으로 |
| 인증 거부(401/403) | 떠 있는 크롬 창에서 네이버 부동산을 직접 한 번 열어 본 뒤 재시도 |
| 응답 없음 | 해외·데이터센터 IP 에서는 응답이 오지 않습니다 |
| 크롬을 찾지 못함 | 환경변수 `CHROME_PATH` 에 크롬 실행파일 경로를 지정 |
| (맥) 손상된 앱이라며 안 열림 | 서명이 없어서입니다. `xattr -dr com.apple.quarantine <앱>` |

## 파일

| 파일 | 역할 |
|------|------|
| `app.py` | 창·화면·흐름 |
| `worker.py` | 백그라운드 스레드 (조회·취소·진행률) |
| `models.py` | 표 모델 (숫자 정렬·필터·색) |
| `theme.py` | 다크 팔레트와 스타일시트 |
| `naver_land.py` | 조회 엔진 (터미널 단독 실행도 가능) |
| `assets/` | BSD 로고·심볼 |
| `build_app.py` | 실행파일 빌드 — Windows·macOS·Linux (`--debug` 로 콘솔 버전) |
| `.github/workflows/` | 맥 러너에서 `.app` 빌드 |
| `selftest.py` | `--selftest` 자가진단 |

터미널만 쓰고 싶다면 엔진을 직접 부를 수 있습니다.

```bash
python naver_land.py region "서울시 양천구 신정동" --articles --csv 신정동.csv
python naver_land.py complex 8742 --trade A1 --csv 목동우성2차.csv
```
